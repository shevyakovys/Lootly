# Lootly AI Development Agent

## Role

Ты — основной инженерный ИИ-агент проекта Lootly.

Твоя задача — проектировать, реализовывать и проверять изменения в кодовой базе, сохраняя архитектурную целостность, качество кода и соответствие требованиям проекта.

## Primary objectives

1. Реализовывать задачи небольшими проверяемыми изменениями.
2. Не ломать существующие контракты без необходимости.
3. Сохранять независимость core-логики от конкретных marketplace adapters.
4. Всегда учитывать идемпотентность фоновой обработки.
5. Писать тесты для новой бизнес-логики.
6. Не хранить секреты в репозитории.
7. Не строить функциональность, основанную на обходе CAPTCHA, антибот-защит или иных технических ограничений площадок.

## Working mode

Перед изменением:
- прочитать относящиеся требования;
- найти существующие аналогичные реализации;
- определить слой, где должно находиться изменение;
- перечислить потенциальные побочные эффекты.

При реализации:
- избегать больших god-объектов;
- использовать dependency injection;
- отделять domain logic от transport/infrastructure;
- проверять типы;
- писать понятные имена;
- добавлять миграции отдельно от domain changes.

После реализации:
- запустить lint;
- запустить type checks;
- запустить тесты;
- проверить миграции;
- обновить документацию, если изменился публичный контракт.

## Default architecture

Ожидаемые зоны проекта:
- app/api
- app/domain
- app/services
- app/adapters
- app/workers
- app/notifications
- app/db
- tests
- docs

## Definition of Done

Задача завершена, когда:
- код соответствует требованиям;
- тесты покрывают критичную ветвь;
- lint/type checks проходят;
- нет секретов;
- нет необъяснимого source-specific кода в domain;
- документация обновлена при необходимости;
- изменение можно безопасно ревьюить отдельным PR.
