# Бизнес-требования Lootly

## 1. Назначение продукта

Lootly — сервис мониторинга объявлений и выявления потенциально выгодных предложений на классифайдах и маркетплейсах. Основная ценность продукта — сократить время между публикацией подходящего объявления и реакцией пользователя.

## 2. Целевая аудитория

Основные пользовательские сегменты:
- частные покупатели, ищущие товары дешевле рынка;
- реселлеры и малый бизнес, закупающие товары для перепродажи;
- коллекционеры и охотники за редкими лотами;
- профессиональные закупщики, отслеживающие заданные категории.

## 3. Основные пользовательские задачи

Пользователь должен иметь возможность:
1. создать мониторинг по URL поиска или набору параметров;
2. задать ценовой диапазон;
3. указать обязательные и исключающие ключевые слова;
4. выбрать регион или географическую область;
5. включить или выключить мониторинг;
6. получать уведомления о новых подходящих объявлениях;
7. видеть оценку выгодности предложения;
8. просматривать историю найденных объявлений;
9. исключать дубли;
10. управлять несколькими мониторингами одновременно.

## 4. Бизнес-ценность

Lootly должен:
- уменьшать время ручного поиска;
- повышать вероятность обнаружения выгодного лота раньше других покупателей;
- помогать пользователю принимать решение на основе сопоставления цены с рынком;
- формировать базу данных для дальнейшей аналитики цен.

## 5. MVP

В MVP входят:
- регистрация пользователя;
- подключение Telegram;
- создание мониторинга;
- хранение конфигурации поиска;
- периодический опрос источника;
- сохранение новых объявлений;
- дедупликация;
- фильтрация;
- Telegram-уведомления;
- базовая оценка скидки относительно типичной цены;
- страница со списком мониторингов;
- страница с найденными объявлениями.

## 6. Не входит в MVP

На первом этапе не обязательны:
- мобильное приложение;
- встроенные платежи;
- автоматические покупки;
- сложные ML-модели;
- поддержка десятков площадок;
- многоуровневая ролевая модель;
- расширенная BI-аналитика.

## 7. Метрики успеха

Базовые продуктовые метрики:
- доля успешно выполненных проверок;
- среднее время от обнаружения объявления до уведомления;
- число активных мониторингов на пользователя;
- число найденных релевантных объявлений;
- CTR по уведомлениям;
- доля отключенных мониторингов;
- количество ложноположительных срабатываний.

## 8. Ограничения

Lootly не должен быть спроектирован вокруг обхода CAPTCHA, антибот-защит, авторизации или технических ограничений сторонних площадок. Для каждого источника данных должен использоваться разрешенный и устойчивый способ интеграции, соответствующий действующим правилам площадки.

## 9. Будущая монетизация

Возможные направления:
- бесплатный тариф с ограничением числа мониторингов;
- платные тарифы с более частыми проверками;
- повышенные лимиты;
- расширенная аналитика цен;
- история рынка;
- приоритетные уведомления;
- несколько источников данных.
