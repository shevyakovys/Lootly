# AGENTS.md — Lootly Booking Platform

Этот файл — обязательная точка входа для любой задачи по проекту.

## Контекст проекта

Lootly теперь является SaaS-платформой онлайн-бронирования для сервисного бизнеса: онлайн-запись клиентов, расписания сотрудников, услуги, филиалы, клиентская база, уведомления и операционная аналитика.

Предыдущая marketplace-концепция отменена и не должна влиять на новые решения.

## Непрерывная работа

Если пользователь поручил продолжать разработку, не останавливайся между успешно завершенными этапами.

Остановка допустима только когда:
1. нужен продуктовый выбор пользователя, который нельзя надежно вывести из требований;
2. нужен credential/секрет/внешний доступ;
3. один блокер не устранен за 3 полных итерации.

Итерация блокера: диагностика → изменение → повторная проверка.

## Definition of Done

Кодовая задача завершена только если:
- требования соблюдены;
- нет двойного бронирования из-за очевидной race condition;
- time zone обработан явно;
- критическая логика покрыта тестами;
- миграции обратимы;
- lint/type checks/tests проходят;
- QA Agent не нашел blocking defects.
